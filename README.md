# SKYBOX Usability 1.3.0 · 中文增强与列表性能优化

适用于 **Steam Windows 版 SKYBOX VR Video Player 1.1.8（2668）**。这是非官方增强补丁，需已合法安装原播放器及 SteamVR。它不是独立播放器，也不提供或绕过 Steam 授权。

## 解压后使用

1. **完整解压 ZIP** 到任意普通文件夹。不要在压缩包预览中直接运行。
2. 完全退出 SKYBOX，双击 **Install.cmd（安装增强补丁）**。
3. 安装器自动寻找 Steam 库。没有找到或有多个位置时，选择包含 `SteamVR_SourceVRPlayer.exe` 的安装文件夹。写入 Program Files 时可能需要 Windows 管理员授权。
4. 安装完成后双击 **Launch-SKYBOX.cmd**，或照常从 Steam 启动。

无需另外安装 SDK、编译器、Python、插件管理器或下载依赖。Windows 10/11 自带的 Windows PowerShell 5.1 和 .NET Framework 可运行安装器。包内同时包含离线源码编译工具，普通使用不需要打开它们。

安装前核对原版程序集 SHA256，安装后核对生成文件；不兼容版本或未知第三方修改会被拒绝。支持的原始 `Assembly-CSharp.dll`：

```text
B6DAD50B364B271BE990F9254BC3EDBBD1CF1BC5455DBF11CB0AC311583C5130
```

## 包含的功能

- 删除选择：全选/取消全选、本排全选/取消本排、全选非收藏。
- 收藏保护：删除确认显示收藏数量，最终执行默认跳过收藏视频；删除含收藏的整个文件夹需额外明确确认。
- 长按文件夹约 0.7 秒：文件夹编辑、删除整个文件夹、统一设置直接子视频的 VR 格式。
- 观看筛选：全部、未看过、看了一部分、已看完；目录保留导航。工具栏位于主面板上方。
- 自动连播跳过已看完；无候选时停止，手动下一段保持原行为。
- 视频卡片显示分辨率和 MB/GB 文件大小，缺失元数据时明确显示未知。
- 自然播放结束保留满进度条并跨重启保存；中途退出保留前后 30 秒范围内的实际续播位置。
- 眼距滑块扩展为 −1～1。
- 播放高级设置：保存全局默认、保存当前视频、保存当前文件夹参数；优先级为单视频 → 直接父文件夹 → 全局。
- 恢复初始默认时保留当前 VR 投影/立体格式。
- 右手摇杆长按约 0.7 秒：收藏/取消收藏，显示“已收藏”或“已取消收藏”提示。
- 右手摇杆短按松开：仅当前视频屏幕调节的倾角、高度、距离、旋转归零。眼距、VR 格式及其他参数保留，文件夹和全局配置不清除。
- 列表性能优化：减少重复扫描、反射与信息格式化，复用原版每帧临时集合，释放换绑后的独立缩略图资源；未降低画质或渲染分辨率。

## 卸载和备份

退出播放器后双击 **Uninstall.cmd**。正常首次安装会把原始 DLL 保存到游戏目录的 `SkyboxUsability.Backup`，卸载恢复其原始字节并移除本补丁扩展。请保留这个备份目录。

卸载不删除视频、收藏、个人播放参数或观看记录。配置位于系统用户目录下：

```text
%USERPROFILE%\AppData\LocalLow\SKYBOX STUDIO\SKYBOX\SkyboxUsability
```

该目录与游戏内的本地备份可能含媒体路径或机器权限信息，不属于公开发布内容，请勿随仓库上传。

早期手工安装的旧补丁如果没有游戏内原始备份，请先用旧安装器恢复原版，再装此包。高级用法可向 `tools\Manage-SKYBOX.ps1` 传入 `-OriginalAssembly` 指向自己合法保留的原始 DLL。已经安装相同最终版本时，重复安装只报告已安装。

## 可选：限制 Steam 更新

**Lock-Steam-Updates.cmd** 和 **Unlock-Steam-Updates.cmd** 是独立可选入口，普通安装不自动启用。操作只针对 SKYBOX 的 Steam 应用 ID 721090，在本地保存原权限及设置后，限制其更新暂存目录写入并将应用清单设为只读。

若 Steam 强制要求更新，锁定可能导致磁盘写入错误或无法启动；用解除入口恢复。它不保证永久冻结版本。更新锁只能可靠恢复本工具保存的状态；使用过早期或其他工具锁定的用户，应先用原工具解除。测试正在下载时会拒绝锁定。

## 使用范围和验证

- 已在匹配版本、RTX 3070、Pimax Crystal/SteamVR 环境进行 VR 交互与列表流畅度复测；其他头显映射及版本需自行核对。
- 原有 81 项策略测试和 6 项性能回归测试通过，另有程序集接入/列表出口/安装回滚检查。
- 观看筛选、眼距、卡片信息、文件夹操作、设置保存、摇杆长短按和列表性能已有实际反馈；自动连播跳过、收藏保护及各层参数的完整组合测试仍应继续，不将局部反馈等同于全部场景验收。
- **测试流畅度时应戴着头显。** 未佩戴时 SteamVR/Pimax 可能待机降频，电脑镜像会显得卡顿；这次已通过运行状态和佩戴对比确认过该现象。
- 完成标记从安装后记录。旧版已经清零的历史不能可靠恢复为“已看完”。
- 整个文件夹删除仅支持 Windows 可直接访问的普通目录；拒绝根目录和链接。网络 URL、不同权限及回收站行为不保证支持。文件夹规则不递归。
- 未实现 Lossless Scaling 到头显的视频插帧桥接，包内没有插帧开关或“小黄鸭”。见 `docs/插帧调研.md`。
- 未量化相对 Steam 原版的整体帧率提升；局部内存分配测试不等于头显帧率提升比例。

## 开发和发布

最终扩展、补丁器及 dnlib 位于 `payload`；C# 源码与测试位于 `source/skybox-patch`。离线 Roslyn 编译器与 dnlib 开发依赖也在源码目录下。二次构建示例：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Rebuild-From-Source.ps1 -GameDirectory "你的 SKYBOX 安装目录" -OriginalAssembly "你保留的原始 Assembly-CSharp.dll"
```

重新构建只写解压目录内的源码构建输出，不改已安装播放器或正式 payload。编译器生成的文件哈希可能不同，不要将重编译文件与原发布清单混用。

可将本 ZIP 作为 GitHub Release 附件，也可把包内源码及工具上传仓库。发行包不包含原版或修改后的 SKYBOX 主程序集、完整播放器、个人配置、媒体、Steam 账号或本机 ACL 备份；安装时在本机生成修改后的程序集。
