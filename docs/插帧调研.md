# 实时插帧调研结论

曾检查 Lossless Scaling 3.2 UI 调用与原生 DLL 导出，以及 SKYBOX 的原生解码纹理、Unity 投影与 OpenVR 路径。

本次未找到该版小黄鸭供 SKYBOX 直接输入视频纹理并取回生成帧的公开接口。桌面镜像插帧不会自动回到头显；单纯启动进程或发热键不足以完成要求。因此本发布包不包含小黄鸭本体、插帧插件或插帧开关，也不承诺 RTX 3070 的 8K 30→60 实时插帧。

继续研究需要在视频进入左右眼投影前实现纹理处理与时序桥接，再验证中间帧、立体一致性、音画同步、跳转与 GPU 耗时。应先低分辨率原型，再测试 4K/8K。

- 实验性 OpenXR 场景插帧项目：https://github.com/tig3rmast3r/OFXR-Bridge

OpenXR 场景插帧与视频源 30→60 是不同验证目标，该实验项目不构成本补丁与 SKYBOX 已兼容的证明。
